== Description ==

Antigeneric is a manifesto-first WordPress block theme built from the ANTIGEN design system. Red/magenta manifesto territories, white evidence spreads, brutal uppercase display typography, and confrontational editorial layouts. Anti-sameness. Anti-stagnation.


== Installation ==

1. Upload the antigeneric folder to /wp-content/themes/
2. Activate via Appearance → Themes
3. Navigate to Appearance → Editor to customise templates and patterns
4. Use the block patterns (Antigeneric category) to build your pages


== Included Patterns ==

- Hero — Manifesto: Full-bleed red hero with stacked headline and CTA
- Three Forces: Triptych layout for Sameness · Stagnation · Suppression
- Evidence Section: Two-column white spread with claim and proof object
- CTA Strip: Closing call-to-action on black background
- Word Wall: Dense buzzword background with overprinted manifesto statement


== Style Variations ==

- Default: Red manifesto (insurgence territory)
- Evidence: Off-white analytical mode (paper territory)


== Typography ==

This theme uses Google Fonts (loaded via CDN):
- Bebas Neue: Display/headline faces
- Montserrat: Body, navigation, UI

Both fonts are loaded from fonts.googleapis.com. If you require self-hosted fonts
for GDPR compliance, replace the Google Fonts enqueue in functions.php with
locally-hosted @font-face declarations.
